# Styx GUI tutorials

Each tutorial builds one model in the Styx GUI, step by step, with a screenshot of each
step. Start with the first one if you are new to Styx.

| Tutorial | What you build | Time |
|---|---|---|
| [CROW excavation wall](CROW_case.md) | A staged sheet-pile excavation in clay and sand, with a strut, an interface, water loads and Mohr-Coulomb soils, up to the bending moment in the wall | about 45 minutes |

The screenshots are made from the GUI each time the code changes, so they show the GUI as
it is.

To install Styx and connect Kratos, see the
[README](../../README.md#getting-started). Every
mode and tool of the GUI is described in
[USAGE.md](../USAGE.md).
